# task-frame

사용 시점: 과제 시작 3~8분, 계획 세션(docs/plan)에서. 사용자가 이미 보낸 1차 질문을 입력으로 받는다.

절차
1. `../README.md`를 읽고 제출물 파일명과 필수조건을 체크리스트로 옮긴다.
2. `../data/` 각 파일의 첫 20줄만 읽어 형식·열·눈에 띄는 품질 문제(중복, 공백, 대소문자, 오타, 결측, 형식 혼재)를 적는다. 그 이상 읽지 않는다.
3. 사용자의 1차 질문과 겹치지 않고 README에 답이 없는 추가 질문 후보 3개를 업무 언어로 쓴다. 각 질문에 "왜 필요한지" 한 줄.
4. 접근안 2개와 추천 이유.
5. 20~65분의 45분 안에 입력→처리→출력이 관통하는 v0 범위.

규칙: 3분 안에 끝낸다. 파일을 만들거나 수정하지 않는다. 기술 용어로 질문하지 않는다. 출력은 위 5개 항목만.
